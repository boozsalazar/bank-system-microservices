# FitManager

Sistema de gestión para gimnasios desarrollado con Java y Spring Boot.

## Tecnologías

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Spring Security
- Maven
- Lombok
- GitHub

## Funcionalidades

- Gestión de usuarios
- Gestión de clientes
- Gestión de membresías
- Gestión de pagos
- Registro de asistencias
- Dashboard administrativo

## Arquitectura

- Controller
- Service
- Repository
- Entity
- Security
